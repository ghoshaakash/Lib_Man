# Auto File Naming and Management

Issue: you have downloaded a bnch of files. More often than not the file names contain stuff you would rather not have it there, or is something incomprehensible. The goal is to monitor files, fix names and metadata and shelf them appropoately.

Flow:

Pre loops:
1. Get your LLM interface ready (done)
2. Get the OCR interface ready (not done)
3. Get the init roles(where libraries are, what shelf to file them into etc) ready (not done)

On loops:

1. Scan for new files(done)
2. OCR first few pages(not done)
3. Send file name+ OCRed data to llm and recieve feedback(not done)
4. Fix metadata, file name and move them to appropiate place(not done)
